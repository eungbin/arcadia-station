작성 기준: 2026-07-23

대상 템플릿: 소피아 의료 사건 / 백준호 정비 사건 / 유나 화물 사건

## 1. 재검토 결론

세 사건의 넓은 사망 유형은 모두 **산소 결핍에 의한 급성 저산소 사망**이다. 그러나 사망에 이르는 메커니즘과 현장 상태는 동일하지 않다.

| 템플릿 | 직접 메커니즘 | 피해자 대응 능력 | 공식 사건 내 사인 표현 |
|---|---|---|---|
| 소피아 | EXP-17로 운동·판단 능력을 낮춘 뒤 의료 프로토콜로 산소 감소 | 약물 때문에 현저히 저하 | EXP-17 중추 억제가 동반된 급성 저산소 사망 |
| 백준호 | BRG-12 예약 작업이 산소를 강제 배출하고 문을 압력 보정 모드로 봉쇄 | 초기에는 정상, 적극적으로 탈출 시도 | 정비용 퍼지 오작동을 가장한 급성 저산소 사망 |
| 유나 | AR-9 아르곤이 실내 산소를 치환하고 압력 격리 모드를 작동 | 경보 후 짧은 시간 대응, 이후 빠르게 저하 | 불활성 가스에 의한 산소 치환성 질식 |

따라서 `CR-01 피해자 시신`의 기본 인물 모델은 재사용할 수 있지만 다음은 사건별 variant여야 한다.

- 시신 위치와 자세
- 손·손목·의복의 조사 포인트
- 주변에 떨어진 물건
- 피해자가 마지막으로 접근한 장치
- 독성 검사 결과
- 환경 센서 결과

시신 외형만으로 세 메커니즘을 확정하게 만들지는 않는다. 급성 산소 결핍 사망의 육안 소견은 비특이적일 수 있으므로, 게임에서도 `시신 관찰 + 현장 상태 + 독성 분석 + 환경/시스템 기록`을 결합해야 정답이 성립하게 한다.

## 2. 오브젝트 변형 등급

| 등급 | 의미 | 구현 방식 |
|---|---|---|
| `C` | 모든 사건에서 동일 | 같은 모델·문구·결과 사용 |
| `T` | 텍스트·로그만 변경 | 같은 3D 모델, 서버 응답 데이터 교체 |
| `S` | 시각 상태 변경 | 같은 베이스 모델에 mesh/material/pose variant 적용 |
| `P` | 등장 여부 변경 | 사건에 따라 증거 오브젝트 또는 정상 상태 오브젝트 표시 |
| `R` | 역할 변경 | 같은 비밀이 핵심 단서 또는 레드헤링으로 변경 |

원칙:

1. 플레이어가 물건의 존재 여부만으로 범인을 맞히지 못하게 한다.
2. 핵심 장치가 없는 사건에서도 정상 부품, 빈 장착대 또는 정상 로그를 조사할 수 있게 한다.
3. 하나의 증거만으로 범인을 확정하지 않는다.
4. 실물 증거와 기록 증거를 최소 하나씩 결합해야 한다.
5. 비활성 템플릿의 살인 단서는 클라이언트와 AI 입력에 전달하지 않는다.

## 12. 구현 데이터 구조

오브젝트는 맵에 직접 정답을 하드코딩하지 않고 템플릿별 상태를 조회한다.

```ts
type ObjectVariant = {
  visible: boolean;
  meshVariant?: string;
  poseVariant?: string;
  interactionText: string;
  evidenceId?: string;
  documentId?: string;
  analysisId?: string;
};

type InteractiveObjectDefinition = {
  objectId: string;
  interactionType:
    | "OBSERVATION"
    | "EVIDENCE"
    | "TERMINAL"
    | "NPC"
    | "DOOR"
    | "WORLD_INFO";
  variants: Record<CaseTemplateId, ObjectVariant>;

```

## 13. 최종 검증 기준

각 템플릿에 대해 다음을 자동 테스트한다.

1. 모든 필수 오브젝트에 현재 템플릿 variant가 존재한다.
2. 비활성 템플릿의 evidence ID가 응답에 포함되지 않는다.
3. 시신 pose와 시신 조사 문구가 템플릿과 일치한다.
4. 실물 증거와 단말 기록이 서로 모순되지 않는다.
5. 범인 조건을 모두 만족하는 인물이 정확히 한 명이다.
6. 핵심 결론마다 서로 다른 출처의 증거가 최소 2개다.
7. AI 심문 없이 공간 조사와 단말 분석만으로 최소 해결 경로가 존재한다.
8. AI에게 전달되는 허용 사실이 현재 템플릿에만 속한다.
9. 사건 완료 전 `caseTemplateId`와 정답이 공개 응답에 노출되지 않는다.
10. 같은 맵을 재사용해도 사건별 물리 상태와 데이터가 명확히 구분된다.

## 14. 기술·법의학 참고

- 아르곤은 산소를 희석해 산소 결핍 환경을 만드는 단순 질식성 가스로 취급한다.
- 급성 산소 결핍 사망은 시신 육안 소견만으로 구체적인 메커니즘을 구분하기 어려울 수 있다.
- 따라서 게임의 정답은 시신 외형이 아니라 현장 조사, 환경 데이터, 독성 검사와 권한 기록의 결합으로 판정한다.
